# Learning Rate Analysis

## Research Question
How does learning rate affect convergence?

## Experimental Setup
- Dataset: Synthetic linear regression
- Epochs: 1000
- Learning rates: 0.1, 0.5, 1.0, 2.0, 5.0
- Same initialization across experiments

## Observations
- Small learning rates converge slowly.
- Appropriate learning rates converge efficiently.
- Excessively large learning rates cause divergence.

## Conclusion
Learning rate strongly influences optimization
speed and numerical stability.
